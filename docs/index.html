Python MCP semantic search

Search markdown by meaning, not exact words.

Markdown FastRAG MCP indexes markdown workspaces in the background, embeds chunks with the provider you choose, and stores vectors in Milvus Lite, Milvus Standalone, or Zilliz Cloud.

Real repository screenshot of MCP semantic search output.

The indexing loop is built for agent concurrency.

Background jobs

index_documents returns a job id immediately, then get_index_status tracks progress.

Fast delta scan

mtime and size skip unchanged files, while deleted files are pruned from the vector store.

Scoped search

scope_path keeps multi-agent searches constrained to the intended workspace area.

Provider and storage choices stay explicit.

Embeddings

Local, Gemini, OpenAI, OpenAI-compatible, Vertex AI, and Voyage provider modes are configured by env vars.

Storage

Milvus Lite is the local default. Set MILVUS_ADDRESS for Standalone or Zilliz Cloud.

Package

Install from PyPI with pip install markdown-fastrag-mcp or run through an MCP host with uvx.

Workspace data should be treated as private.

Secrets

Provider keys are environment variables. Do not publish host configs with literal API keys.

Paths

Vector stores and tracking data can reveal local file paths and note topics.

Verification

Current local gate: python3 -m py_compile server.py utils.py reindex.py chunking.py.
